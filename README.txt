This is my second individual assignment for CIT2011 at the University of Technology, Jamaica. The project involves creating a conference registration website using HTML, CSS, and JavaScript.

The website allows users to enter their information, upload a profile picture, and generate a personalized conference ticket.

Features

* Conference homepage
* Registration form
* Image upload
* Form validation
* Ticket generation
* Responsive layout

Files

* index.html - Homepage
* login.html - Registration form
* ticket.html - Generated ticket
* css/style.css - Website styling
* js/validation.js - Form validation
* js/ticket.js - Ticket generation

How to Run

Download the project and open index.html in a web browser.

Technologies

HTML, CSS, JavaScript
